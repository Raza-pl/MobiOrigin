# MobiOrigin publication and release checklist

## Completed in the repository

- Frozen three-seed MobiOrigin model, normalization, selective threshold, and safe loader.
- Source-disjoint development, calibration, locked-test, and prospective external evaluations.
- Prospective external MobiOrigin-versus-geNomad comparison with paired source-level inference.
- Aggregate publication tables, editable vector figure, methods, and claim boundaries.
- Top-level MobiOrigin user documentation, legacy PlasFlow2 preservation, output schema, and migration guide.
- Atomic exact-hash marker-database setup command; databases remain unbundled.
- Versioned citation metadata and changelog.
- Manuscript draft with frozen aggregate results and explicit limitations.

## Author confirmation required before journal submission

- Supply and approve affiliation and postal address.
- Approve funding, competing-interests, and CRediT contribution statements.
- Select the target journal and apply its article template, word limit, and reference style.
- Approve the final title, abstract, author list, and correspondence details.
- Decide whether protected record-level cohort material can be deposited under controlled access or must remain unavailable.

## Hosting actions requiring authenticated external services

- Rename or transfer the historical GitHub repository if a MobiOrigin-specific slug is desired.
- Create the public tagged GitHub release and attach release notes.
- Connect the release to Zenodo or another archive and add the minted DOI to `CITATION.cff` and the manuscript.
- Submit the manuscript and supplementary files through the selected journal portal.

None of these external actions may change the frozen model, selective threshold, external endpoints, comparator semantics, or reported results.
