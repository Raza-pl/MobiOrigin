# MobiOrigin prospective external-validation evidence

This directory contains publication-facing aggregate artifacts derived from the frozen prospective external MobiOrigin-versus-geNomad comparison. It deliberately excludes record-level labels, predictions, sequences, and model-tuning material.

- `table_1_external_comparison.tsv`: principal aggregate comparison table.
- `table_s1_co_primary_inference.tsv`: preregistered paired inference with Holm adjustment.
- `table_s2_length_bin_descriptive_metrics.tsv`: descriptive length-bin results.
- `figure_1_external_comparison.svg`: editable vector summary figure.
- `methods_external_validation.md`: concise reproducible methods text.
- `claims_and_limitations.md`: frozen claim boundaries and required trade-off disclosure.

## Post-hoc secondary comparator supplement

The frozen external cohort was also evaluated against PlasClass, PlasFlow v1, PLASMe, and Platon as a clearly separated exploratory post-hoc analysis.

- `table_s3_secondary_comparator_plasmid_binary_metrics.tsv`: common plasmid-binary point estimates.
- `table_s4_secondary_comparator_paired_exploratory.tsv`: paired bootstrap differences with eight-test Holm correction.
- `figure_s2_secondary_comparator_plasmid_binary.svg`: editable summary figure.
- `methods_secondary_comparator_analysis.md`: methods and statistical policy.
- `claims_and_limitations_secondary_comparators.md`: mandatory interpretation boundaries.
